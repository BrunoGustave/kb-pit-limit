# KB Pit Limit — application web hors ligne

Fosse en 3D, position GPS sur le pit design, limite de fosse, blocs de matériaux et volumes restant à miner.

**iPhone / iPad** : ouvrir le lien de ce site dans **Safari** → bouton **Partager** → **Sur l'écran d'accueil**, puis ouvrir l'icône une première fois avec réseau. Ensuite l'application fonctionne sans connexion.

**Android** : utiliser de préférence l'APK ; sinon Chrome → menu ⋮ → **Installer l'application**.

Les fichiers importés (.00t, .dtm/.str, .dxf…) restent dans l'appareil : rien n'est envoyé sur internet.
